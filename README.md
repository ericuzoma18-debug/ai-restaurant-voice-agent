# AI Restaurant Voice Agent

An AI-powered voice agent designed to help restaurants handle customer calls, respond to enquiries, and automate information collection.

## Project Overview

Restaurants often receive repetitive customer enquiries that require staff time and attention. This project explores how AI voice technology and workflow automation can help streamline customer interactions and capture information efficiently.

## How It Works

1. A customer interacts with the restaurant's AI voice agent over a phone call.
2. The AI voice agent listens to the customer and responds conversationally.
3. The system processes the conversation and collects relevant information.
4. Customer information can be recorded in Google Sheets for tracking and follow-up.

## Key Features

- AI-powered voice conversations
- Automated handling of restaurant enquiries
- Conversational customer interaction
- Customer information capture
- Google Sheets integration

## Technologies Used

- **Vapi** — AI voice agent
- **Twilio** — Phone call integration
- **OpenAI** — AI conversation capabilities
- **Google Sheets** — Customer information storage
- **n8n** — Workflow automation
